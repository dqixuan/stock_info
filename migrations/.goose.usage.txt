=================================================================
  Goose 数据库迁移工具 - 快速参考
=================================================================

📦 已安装版本: goose v3.15.0
📍 安装路径: ~/go/bin/goose
📂 迁移目录: ./migrations

-----------------------------------------------------------------
  快速开始
-----------------------------------------------------------------

1️⃣  配置数据库（首次使用）
   cp .goose.env .goose.env.local
   编辑 .goose.env.local 修改数据库连接

2️⃣  查看迁移状态
   make migrate-status

3️⃣  执行迁移
   make migrate-up

-----------------------------------------------------------------
  常用 Make 命令
-----------------------------------------------------------------

make migrate-status      # 查看迁移状态
make migrate-up          # 执行所有待执行的迁移
make migrate-up-one      # 只执行下一个迁移
make migrate-down        # 回滚最后一个迁移
make migrate-reset       # 回滚所有迁移（危险！）
make migrate-version     # 查看当前版本
make migrate-create name=<name>  # 创建新迁移

-----------------------------------------------------------------
  示例：创建新迁移
-----------------------------------------------------------------

# 使用 Make
make migrate-create name=add_user_watchlist

# 直接使用 goose
goose -dir migrations create add_user_watchlist sql

-----------------------------------------------------------------
  数据库连接配置
-----------------------------------------------------------------

默认配置（可通过环境变量覆盖）：

DB_DRIVER = mysql
DB_STRING = root:root@tcp(127.0.0.1:3306)/stock_info?parseTime=true

自定义连接：
export DB_STRING="user:pass@tcp(host:port)/dbname?parseTime=true"
make migrate-up

-----------------------------------------------------------------
  故障排除
-----------------------------------------------------------------

❌ 错误：goose: command not found
   解决：export PATH=$PATH:~/go/bin

❌ 错误：dial tcp 127.0.0.1:3306: connect: connection refused
   解决：确保 MySQL 服务已启动

❌ 错误：Access denied for user
   解决：检查数据库用户名和密码
